How the frontend connects

The local C++ web server calls the added JSON bridge. The bridge uses your existing InjectionTest subclasses, TestRunner, ResponseAnalyzer, TestExecutionCoordinator, TestResult and TestRun. No original engine behavior was changed.

Results are temporary. Export the report before closing or reloading. IDs belong to each run; the C++ coordinator starts new result IDs for every run.
